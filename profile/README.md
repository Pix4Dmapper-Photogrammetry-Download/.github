# Pix4Dmapper — Photogrammetry for Aerial Mapping
Pix4Dmapper is a photogrammetry application for Windows that converts aerial images into georeferenced maps, point clouds, and 3D models.
Its project workflow guides users from image import and calibration through reconstruction, measurement, inspection, and export.

</details>

<details>
<summary><b>Which versions of Windows are supported?</b></summary>

Current Pix4Dmapper system requirements specify 64-bit Windows 10 or Windows 11. Processing performance also depends on the project size, available memory and storage, processor, and an OpenGL-compatible graphics device.
</details>

<details>
<summary><b>What can I create with Pix4Dmapper?</b></summary>

The application processes overlapping images into outputs such as point clouds, three-dimensional meshes, orthomosaics, elevation models, and project measurements. Available results depend on the source imagery and selected processing options.
</details>

<details>
<summary><b>Does Pix4Dmapper require an account?</b></summary>

Yes. The first launch includes account sign-in and selection of an available license or the limited discovery mode.
</details>

## Who Uses Pix4Dmapper

Pix4Dmapper is designed for surveying, mapping, construction, inspection, agriculture, public-safety, research, and other professionals who need to turn overlapping aerial or terrestrial imagery into measurable spatial outputs.
